# NovaMart Multi-Agent Customer Support System

This ZIP archive contains the complete production-grade implementation of the NovaMart Multi-Agent Customer Support System built with Amazon Bedrock AgentCore, Strands Agents SDK, DynamoDB, S3 Vectors, and X-Ray Observability.

## Submission Deliverables Included:
1. `src/agent_orchestrator.py`: Full implementation of Tasks 2, 3, 4, and 6 (Inventory, Refund, Policy, Communication, Orchestrator agents, guardrail creation, memory configuration, and observability).
2. `.env`: Configured with Knowledge Base IDs and runtime ARNs.
3. Architecture & test documentation.
